# Purpose and disclaimer

This guide is a minimal quickstart for using the equipment in the Robotics Laboratory course. It covers the normal workflow: simulation, programming, operation of the robot cell, and vision.

{: .warning }
> **This is not an operating or safety manual.** Always follow the official manuals for the robot cell and every component. If this guide conflicts with an official manual or with an instructor's direction, use the official source or instructor's direction.

The linked official manuals are the ground-truth reference. **Please report errors or inconsistencies** in this guide to the course instructor.
